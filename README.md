# E-commerce

## 📌 Описание
Проект находится в разработке. 

Цели:

- спроектировать нормализованную структуру БД для и написать SQL-запросы для работы с данными
- разработать рекомендательную систему товаров
- введение в production с помощью FastApi или Flask
